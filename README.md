# ⚔️ 地牢切怪大冒險 - 質因數分解雙人對決

🎮 **線上直接玩**：[點此進入遊戲](https://kakafish1022.github.io/math-dungeon/)

## 專案用途
國中七年級數學「質因數分解」教學輔助遊戲。學生透過操作質數神劍（2、3、5、7）進行短除法切怪，訓練整除性判別與標準分解式概念。

## 核心機制
- **雙人連線**：使用 PeerJS (WebRTC) 透過 4 碼房間代號直接直連，無需後端伺服器。
- **作答懲罰**：無法整除時會彈刀並強制凍結操作 5 秒。
- **單機模式**：提供暗影 AI 對手，學網防火牆阻擋或落單時可單人練習。
- **結算動畫**：獲勝端滿版煙火，落敗端拳套重擊 KO，支援雙方同意再戰與休兵協議。
